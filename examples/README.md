# Examples

- `claim_evidence_demo.py`: deterministic claim/evidence state transitions.
- `protocol_trace_demo.py`: traceable scientific protocol execution.
- `method_integration.py`: local method registration, execution, qualification, and delivery.

The interactive Web workspace also retains the six featured case cards from BioMA.
Those cards are examples of supported artifact presentation and historical runs; they
are not bundled datasets and do not claim that a fresh run will reproduce the result
without the required data, software, model access, and compute environment.
