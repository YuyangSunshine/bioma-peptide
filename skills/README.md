# Curated scientific skills

This repository carries a compact peptide-oriented subset of BioMA's skill catalog:
sequence and structure analysis, peptide/protein design, docking, developability,
scientific literature, reporting, and visualization.

Skills describe procedures, applicability, and tool bindings in `SKILL.md`. They are
guidance—not execution permission, an execution receipt, or scientific evidence.
Executable wrappers under a skill's `scripts/` directory are still subject to the
same runtime grants and verification boundaries as tools in [`tools/`](../tools/README.md).

`_meta/` preserves stable upstream identities and attribution. The loader selects
only packages physically shipped in this repository, so a historical metadata entry
for an omitted package does not make that package available at runtime.
